# EstanteWeb — Sessão e Login

Projeto desenvolvido em Java utilizando Spring Boot.

## Sobre o projeto

O EstanteWeb é uma aplicação web voltada ao gerenciamento de livros, permitindo a visualização e o gerenciamento de livros, o envio de sugestões e o acesso por meio de uma funcionalidade de login.

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Maven
- MySQL
- FreeMarker
- Flyway

## Funcionalidades

- Sistema de login
- Gerenciamento de livros
- Cadastro e edição de livros
- Remoção de livros
- Cadastro e visualização de sugestões
- Páginas web utilizando FreeMarker

## Banco de dados

O projeto utiliza MySQL para armazenamento dos dados e Flyway para gerenciamento das migrações do banco de dados.

## Como executar

1. Instale o Java 17.
2. Instale e configure o MySQL.
3. Configure as credenciais do banco de dados no arquivo `application.properties`.
4. Execute a aplicação utilizando Maven.
